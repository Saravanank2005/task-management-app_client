# Task360 - Frontend Client

> **Task360 React Web Application**

Task360 is a simple, modern task management web interface built with **React (JSX)**, **Vite**, and **Vanilla CSS**.

## ⚡ How to Run Locally (Offline / Dev Mode)

1. Open terminal in the `client` folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create `.env` file:
   ```env
   VITE_GOOGLE_CLIENT_ID=674600937844-sbkl3phfi8g8cene5ektcco0rnac5ja2.apps.googleusercontent.com
   ```
4. Start local development server:
   ```bash
   npm run dev
   ```
5. Open your browser at `http://localhost:3000`.

## 🚀 Key Features

- **Google OAuth & Instant Demo Sign In**: Sign in with your Google account or click **"Task360 Demo Account"** for instant access.
- **Task Management**: Create tasks, update status (**Planned**, **In Progress**, **Complete**), edit, and delete.
- **Filter & Search**: Real-time keyword search and status category filters.
